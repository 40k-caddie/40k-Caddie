# 40k Caddie

A Warhammer 40,000 11th edition game companion. Install it from your phone's browser: Share, then Add to Home Screen.

- `index.html`, `app.js`, `data.js`, `foes.js`, `factions/`: the app and its rules data (from Wahapedia)
- `lib/`: the image library
- `sb.js`: account sync through Supabase
- `rules-status.json`: written each week by `.github/workflows/rules-check.yml`
- `supabase/schema.sql`: database setup, run once in the Supabase SQL editor
